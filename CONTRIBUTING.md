# Contributing

## Ветки и Pull Request'ы

- `main` — стабильная ветка, прямые push в неё запрещены.
- Работа ведётся в ветках `feature/<краткое-имя>` (одна задача — одна ветка).
- Слияние — только через Pull Request с ревью второго участника.
- Изменения в аутентификации/авторизации — обязательное **двойное** ревью (ЛР 1, п. 4.4).
- В описании PR указывается номер задачи (`Closes #N`) и закрываемое требование (FR-xx / NFR-xx).

## Коммиты

- Сообщение: краткое описание сути на русском или английском, в повелительном наклонении.
- Коммиты небольшими атомарными порциями, не смешивать несколько задач в одном коммите.

## Перед созданием PR

- Локально проверить запуск приложения и миграции.
- Убедиться, что не коммитятся: `.env`, виртуальное окружение, временные файлы, служебные `.lab*.md` / `.tasks_current.md`.

## Тестирование

- Бэкенд: pytest (`pytest` в каталоге `backend/`).
- Перед merge — ручная проверка по Definition of Done задачи.
