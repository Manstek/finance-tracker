# Трекер финансов — фронтенд

HTML/CSS/JavaScript без сборки (ES-модули). Макеты экранов — `mockups/`.

## Запуск

ES-модули не работают через `file://`, нужен локальный сервер:

```bash
cd frontend
python -m http.server 5500
```

Открыть http://localhost:5500. Бэкенд должен быть запущен на http://localhost:8000 (см. `backend/README.md`); адрес API — в `js/config.js`.

## Структура

```
frontend/
├── index.html        # оболочка: шапка, меню, контейнер #app
├── css/styles.css    # общие стили, переменные цветов
└── js/
    ├── config.js     # API_BASE
    ├── api.js        # API-клиент по backend/docs/api.md, хранение JWT, обработка 401
    ├── router.js     # hash-роутер (#/login, #/operations, ...)
    ├── format.js     # суммы "1 500,00 ₽", даты ДД.ММ.ГГГГ, текущий месяц
    └── app.js        # маршруты, защита страниц, заглушки экранов
```

## Договорённости

- Токен хранится в `localStorage`; при ответе 401 — выход и переход на `#/login`.
- Гость видит только `#/login` и `#/register`, остальные маршруты требуют входа.
- Экраны наполняются в задачах этапа 2: #17 (вход/регистрация), #18 (список операций), #19–#21.
- Пункт «Администрирование» скрыт, пока бэкенд не отдаёт `is_admin` текущего пользователя (предложено `GET /auth/me`).
