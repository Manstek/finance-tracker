# Макеты экранов (#6)

Каркасные макеты (wireframes) основных экранов «Трекера финансов». Открыть в браузере: `frontend/mockups/index.html`.

| Экран | Маршрут | Требования | Кто видит |
|---|---|---|---|
| Вход | `#/login` | FR-2, UC-2 | гость |
| Регистрация | `#/register` | FR-1, UC-1 | гость |
| Операции: список, фильтры, итоги | `#/operations` | FR-4…FR-8, UC-4…UC-8 | пользователь |
| Форма операции (модальное окно) | — | FR-4, FR-8, FR-12 | пользователь |
| Категории | `#/categories` | FR-10, UC-10 | пользователь |
| Статистика (круговая диаграмма) | `#/statistics` | FR-9, UC-9 | пользователь |
| Администрирование | `#/admin` | FR-13, UC-11 | администратор |

## Принципы (NFR-3)

- Интерфейс на русском, основные действия — не более 2 кликов: «+ Операция» всегда в шапке экрана операций.
- Ошибки ввода показываются под полем, ошибки сервера — сообщением над формой (`detail` из ответа API).
- Суммы: доходы — зелёным со знаком «+», расходы — красным со знаком «−»; формат `1 500,00 ₽`.
- Даты в интерфейсе `ДД.ММ.ГГГГ`, в API — `YYYY-MM-DD` (см. `backend/docs/api.md`).
- По умолчанию список показывает текущий месяц; итоги (доходы / расходы / баланс) считаются за выбранный период.
- Операции без категории (категория удалена) — «Без категории».
- Пункт меню «Администрирование» виден только при `is_admin = true`.
- При 401 (токен истёк) — выход и переход на экран входа.

## Навигация

```
Вход ⇄ Регистрация
  └─(успешный вход)→ Операции ⇄ Категории ⇄ Статистика
                         └─ Администрирование (только админ)
```
